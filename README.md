# 考公台历 · gongkao-app

小米平板 / 安卓手机用的**全屏常亮台历 + 考试倒计时**，左栏为公历 / 农历 / 国考与省考
倒计时，右半屏轮播考公内容（行测常识 / 高频成语 / 时政热词）；右上角可切到**番茄工作法**
（25/5/15，时长可配）、**计时工具**（倒计时 / 秒表）、**今日足迹**（当天 App 使用统计）；
另有**AI 规划**（登录主站账号，读你的做题数据，生成可勾选备考清单）。基于 **Flutter**，
打成安卓 apk 安装到设备。

选型取「性能 × 跨端」两项（用户裁定）：Flutter 是性能接近原生、又能全平台跨端的唯一
同时满足者。完整对比见方案文档 §二。

实现分两阶段（见方案 §十）：**Phase 1** 离线（台历 / 番茄钟 / 计时工具 / 今日足迹 / 背景音）；
**Phase 2** 联网（登录主站 + AI 规划）。

> 状态：**Phase 1 已可装机运行**；Phase 2（联网 / AI 规划）未开工。
> 方案与逐项裁定见 [`docs/平板台历方案.md`](docs/平板台历方案.md)，后续待办见其 §十二。

## 已实现（Phase 1）

- **台历**：公历大字 + 农历 / 干支 + 星期，右下倒计时含**国考**与**辽宁省考**（`lib/config.dart` 可改）。
- **内容轮播**：常识 / 成语 / 时政三类卡片，按主题筛选、可调轮播间隔。
- **番茄钟**：25/5/15 专注循环，单独一屏。
- **计时工具**：倒计时（时:分:秒按位可拨滚轮 + 快捷时长）/ 秒表。
- **今日足迹**：读系统使用统计，展示当天 App 使用总览与**时间线**（需授予「使用情况访问」权限）。
- **响应式**：平板横屏两栏 / 手机竖屏单栏，一套代码自适应。
- **返回键**：子页先回台历；台历页两秒内连按两次才退出。

## 与主站的关系

本仓**独立**，与 [`gongkao`](../gongkao)（读本 READBOOK 主站）**无关**：

- 不接入主仓 pnpm workspace，不参与其构建 / 部署 / 门禁。
- 内容以**镜像**方式取自 `gongkao/data/` 下的三份 JSON，见方案文档 §三。
- 主站怎么改都不影响本工程，反之亦然。

## 快速开始

```bash
flutter pub get
node scripts/sync_data.mjs        # 从 ../gongkao/data/ 镜像内容
flutter run                       # 调试
flutter analyze                   # 静态检查
flutter build apk --release       # 出 apk
```

> 「今日足迹」需在设备「设置 → 应用 → 特殊权限 → 使用情况访问」里手动授予本应用权限；
> 未授权时页面会给出「去授权」入口。数据仅在本机展示，不上传。

## 常用改动

- **改考试日期 / 轮播间隔 / 番茄时长 / 断点阈值**：`lib/config.dart`（考试在 `examTargets`）。
- **刷新内容**：重跑 `node scripts/sync_data.mjs`
- **补背景音素材**：把无缝循环的白噪音放进 `assets/audio/`，并在 `lib/config.dart` 登记
